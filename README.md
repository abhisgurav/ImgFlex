# 🖼️ ImgFlex – Online Image Editor & Converter

ImgFlex is a simple, modern, and user-friendly image editing tool designed to make image editing easier. It provides essential image manipulation features, including image format conversion, resizing, filters, adjustments, and transformations — all in one place.

Whether you want to resize an image for social media, convert an image into another format, or enhance its appearance, ImgFlex makes the process simple and convenient.

✨ Features
🔄 1. Format Converter

Convert images between different image formats quickly and easily.

Convert images between PNG, JPG, WEBP, and other supported formats.
Simple and user-friendly interface.
Convenient image export.

📐 2. Smart Resizer
  
Resize images according to your requirements using predefined dimensions or custom sizes.

Available Resize Presets:

Preset	Dimensions
Custom	User-defined dimensions
Instagram Square	1080 × 1080
Twitter / Facebook Post	1200 × 630
YouTube Thumbnail	1280 × 720
Full HD	1920 × 1080

🛠️ Technologies Used

ImgFlex is built using standard web technologies:

    HTML5 – Website structure and layout.
    CSS3 – Styling, responsive design, and user interface.
    JavaScript – Image editing functionality and interactive features.
    HTML Canvas API – Image rendering and manipulation.

🚀 Getting Started

Follow these steps to run ImgFlex on your local machine.

1. Clone the Repository  
    git clone https://github.com/abhisgurav/ImgFlex.git

2. Navigate to the Project Folder
    cd ImgFlex

3. Run the Project
    Open the index.html file in your browser. Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.

ImgFlex aims to combine essential image editing tools into one convenient platform.
